skim in the browser

Click the terminal, then move with j k. Fold with za, fold all with zM, open all with zR. Change the view with s. Search with /. Read the help with ?.

Press Enter on a code line to write a comment. The editor is vim: Enter saves, Shift+Enter adds a line, Esc then :q cancels. On a saved comment, d deletes it and D deletes them all.
